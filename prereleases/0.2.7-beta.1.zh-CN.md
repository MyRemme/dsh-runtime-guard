# DSH Runtime Guard 0.2.7-beta.1

此处归档 UI 预发布版本，安装包使用 `0.2.6` 后端及其依赖，保存的是本次对话中已经完成并安装到本机的版本。预发布分支已合并到正式版 `main`；正式版保留 `0.2.7` 较新的实现及后端，归档安装包不替换正式版安装包，也不更新 `updates/stable.json`。

## 界面变更

- 实时监控使用概览、对话卡片和检测记录布局，监控设置在宽面板分两列显示。
- 插件更新页内容居中。
- 移除全屏按钮及对应代码。
- 对话组件使用 DSH 原生 `MenuSurface`，材质与原生模型选择菜单一致。
- 展开详情后在独立内层滚动，磨砂背景始终覆盖整个卡片。
- 使用独立 `rg26-` 样式前缀，避免与旧 Flash Stabilizer 界面冲突。

## 安装包

同目录的 `dsh-runtime-guard-0.2.7-beta.1.tgz` 是已交付压缩包的原始副本，没有重新打包。`checksums.sha256` 提供 SHA-256 校验值。

```powershell
dsh plugin --profile desktop add './dsh-runtime-guard-0.2.7-beta.1.tgz'
```

## 验证记录

此前已完成桌面、窄窗口和手机尺寸的预览验证，明暗主题滚动验证，以及本机 DSH 真实对话卡片验证。磨砂材质与原生模型菜单一致，滚动后背景完整覆盖，更新页居中且无全屏入口。

按用户要求，打包和提交阶段不追加测试。这份安装包沿用此前验证过的文件；本分支同步了客户端测试的组件与选择器适配，但未重新运行。

本机热更新安装器的失败回退与成功记录保留也已修复并通过隔离验证。该安装器属于本机部署辅助工具，不随插件安装包分发。
